# 🧠 Fake News Detector

A full-stack AI-powered web application that detects whether a news article 
is real or fake using Machine Learning (NLP).

## Tech Stack
- **ML:** Python, Scikit-learn, NLTK, TF-IDF
- **Backend:** FastAPI, PostgreSQL, SQLAlchemy
- **Frontend:** React.js, Tailwind CSS, Axios
